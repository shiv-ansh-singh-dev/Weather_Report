# 🌦️ WeatherWatch : Multi-City Power BI Dashboard  

![Power BI](https://img.shields.io/badge/Tool-Power%20BI-yellow?logo=powerbi)
![Excel](https://img.shields.io/badge/Data-Excel-green?logo=microsoft-excel)
![DAX](https://img.shields.io/badge/Formula-DAX-blue)

Tools & Tech: Excel · Power BI · DAX · Weather API

📊 Designed an interactive real-time weather dashboard in Power BI covering 5 cities with live API integration.

🌡️ Visualized key weather KPIs: Temperature (28.1 °C), Humidity (100%), Wind Speed (6.8 km/h), Pressure (1001 hPa), and Rain Probability (up to 89%).

🌍 Integrated Air Quality Index (AQI) metrics — PM10 (41), PM2.5 (38), CO (514), O₃ (118) — enriched with health-based insights using DAX-driven conditional logic.

📈 Delivered clear city-level comparisons and dynamic visuals (gauges, KPI cards, trend lines) for intuitive monitoring.

Enhanced decision-making for environmental awareness through data storytelling and KPI-driven insights.
